# COS 201 — Computer Programming I
## Week 3 Practical: Variables, Data Types, Expressions, and Input/Output

### Overview
This repository contains the Java solutions for the Week 3 practical submission for COS 201. The programs demonstrate the use of basic Java variables, primitive data types, arithmetic expressions, and user input/output handling using `java.util.Scanner`.

---

### Programs Included

1. **`SimpleCalculator.java`**
   - **Description:** Accepts two floating-point numbers from the user and performs basic arithmetic operations (addition, subtraction, multiplication, and division). It includes zero-division handling.

2. **`AverageCalculator.java`**
   - **Description:** Prompts the user for three numeric values (such as test scores) and calculates their arithmetic mean.

3. **`ItemCost.java`**
   - **Description:** Computes the total price of an item given its name, quantity, and unit price.
